# vision_caller 意图映射

## 触发场景

| 用户表达 | 参数 |
|---|---|
| 「你能看图吗」 | 全部留空 |
| 「你的眼睛好了吗」 | 全部留空 |
| 「你现在用的什么视觉模型」 | 全部留空 |
| 「为什么看不了我的图」 | 全部留空 |
| 「用 glm-4v 能看图吗」 | `prefer_model="glm-4v"` |

## 不该触发

| 用户表达 | 应走 |
|---|---|
| 「看看这张图」 | `vision_analyze` → `analyze_image` |
| 「这两张图哪不一样」 | `vision_analyze` → `analyze_images` |
| 「你有什么功能」 | 通用能力自述，非本技能 |

## 参数陷阱

- 本工具**不接受** `image_url`。模型若想传图，说明它该调 `analyze_image`
- `prefer_model` 只在用户明确点名某个模型时才传，平时留空
- 探测结果为「不具备」时，回复应转述原因而非简单说「不行」，原因文本已在返回值中
