# 视觉检索

补上「带图提问」这个缺口：内置 `web_search` 只吃文本，图片信息进不去检索。

## 工具

| 工具 | 用途 | 配额 |
|---|---|---|
| `visual_web_search` | 图 → 关键词 → 联网检索 | 每会话 2 次 |

## 为什么不叫 web_search

内置工具已占用 `web_search` 这个名字，且实现完整（含多引擎降级）。
本技能注册为 `visual_web_search`，**不覆盖**内置工具——
工具注册表对同名会静默覆盖，重名会让纯文本检索一并变慢变贵。

## 三条检索链路的分工

| 场景 | 走哪个 |
|---|---|
| 纯文本单路查询 | 内置 `web_search` |
| 多角度交叉求证 | `web_research` → `deep_research` |
| 带图提问 | 本技能 → `visual_web_search` |

## 流程

1. 并发拉取图片（最多 2 张）
2. 并发用视觉模型抽关键词，提示词约束「只输出关键词、认不出就输出空」
3. 清洗线索：空白归一 + 60 字符截断（视觉模型常无视格式约束吐出整句）
4. 与原查询按词去重后拼接
5. 走 `llm_helper.web_search` 检索

## 失败降级

| 失败点 | 行为 |
|---|---|
| 单张图下载/识别失败 | 该图不产出线索，其余图与原查询继续 |
| 全部图无线索 | 退化为按原查询检索 |
| 原查询与线索都为空 | 提示补充文字描述 |
| 整体超过 40 秒 | 返回超时提示 |

返回值会带上实际使用的检索词与线索图数量，便于用户判断结论可信度。
