# web_search 意图映射

## 触发场景

| 用户表达 | 参数要点 |
|---|---|
| 「这个多少钱」+图 | `query="价格 多少钱"`，图 URL |
| 「这是哪」+风景图 | `query="这是哪里 地点"` |
| 「这是哪部动画」+截图 | `query="出自哪部作品"` |
| 「这个牌子怎么样」+商品图 | `query="口碑 评价"` |
| 「这本书讲什么」+封面 | `query="内容简介"` |

`query` 写「问的方向」而非完整句子——它会和视觉线索拼成检索串，
完整句子会稀释关键词权重。

## 不该触发

| 用户表达 | 应走 |
|---|---|
| 「今天天气」 | 内置 `web_search` 或 `weather` |
| 「比特币现在多少钱」 | 内置 `web_search`（无图） |
| 「查一下这三个说法哪个对」 | `web_research` → `deep_research` |
| 「图里有什么」 | `vision_analyze` → `analyze_image` |
| 「这张图好看吗」 | `vision_analyze`，主观评价不需要联网 |

## 参数陷阱

- **无图时不要用本工具**。没有 `image_urls` 时它退化成一次普通检索，
  却多绕一层且配额更紧，直接用内置 `web_search`
- 图片超过 2 张会被截断，挑最能说明问题的传
- 返回值里的「检索词」是实际用的增强查询，回复时若结论跑偏可据此判断
  是线索抽错了还是检索没结果
- 每会话仅 2 次配额，不要用它做试探性检索
