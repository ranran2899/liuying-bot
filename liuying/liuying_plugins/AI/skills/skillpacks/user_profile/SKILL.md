在长期记忆之上补齐「主动写入」与「画像汇总」两个能力，
与只读的内置 `recall_memory` 形成互补。

提供两个工具：

- `remember_fact`：把关于当前用户的重要事实写入长期记忆
- `get_user_profile`：列出已记住的全部要点

安全设计：

- 用户身份取自 Agent 会话上下文，不作为工具参数暴露
- 模型无法指定 user_id，从结构上杜绝越权读写他人记忆
- 写入配额每会话 3 次，防止把闲聊刷成记忆

写入策略：

- tier 固定为 `long`，直接进长期记忆
- salience 取 0.8，高于被动抽取的默认值，检索时优先命中
- 单条内容上限 200 字符，超出截断

调用建议：

- 值得写入：喜好、职业、称呼偏好、纪念日、明确的长期约定
- 不要写入：一次性的闲聊、临时情绪、可从上下文直接看到的内容
- fact 写成完整陈述句（「喜欢喝冰美式」），不要写成对话片段
